## 3. 詳しい説明（4000 文字以内）

```
Pictobi は、端末に保存した写真を「フォルダから探して、すぐ見る」ことに特化した画像ビューアです。
大量の写真がある端末でも、待たされずに一覧が開きます。

■ 大量の写真でも軽快に
写真の情報を端末内にキャッシュし、起動時はそれを読むだけにしています。
35万枚規模のライブラリでも、フォルダ一覧をすぐに表示します。
写真そのものをコピーしたり、別の場所へ移動したりはしません。

■ フォルダで探せる
端末のフォルダ構成をそのまま一覧にします。フォルダ名で検索でき、
よく見るフォルダはお気に入りに登録できます。
「前回の続き」から、前回見ていた写真へすぐ戻れます。

■ タグで整理できる
フォルダにタグを付けて、タグで絞り込めます。
複数のタグを AND / OR で組み合わせた絞り込みにも対応しています。
検索結果の複数フォルダへ、タグをまとめて付与することもできます。

■ 見るための操作
・ピンチで列数を変更（一時的な変更で、設定は変わりません）
・ダブルタップで拡大、スワイプで前後の写真へ
・ページスクラバーで、フォルダ内の好きな位置へ移動
・前後のフォルダへそのまま移動
・ランダムジャンプ

■ 戻っても消えない
画面遷移・アプリ復帰・プロセス再生成のあとも、一覧と閲覧位置を復元します。
スクロール位置はフォルダごと、並び順ごとに記憶します。

■ オフラインで完結
ネットワーク権限を持っていません。写真も閲覧履歴も端末の外へ送りません。
広告・解析 SDK・アカウント登録はありません。

■ バックアップ
タグ・お気に入り・除外フォルダ・表示設定を JSON ファイルへ書き出せます。
機種変更や再インストールの前に書き出しておくと安心です。
書き出し忘れを防ぐため、前回の書き出しから日が経つと控えめに案内します。

■ こんな方に
・端末に写真が数万枚以上あり、標準のギャラリーが重い
・フォルダ単位で写真を管理している
・タグで横断的に整理したい
・余計な機能や通信がないビューアがほしい

■ 注意
・写真の削除・編集はできません。閲覧に特化しています。
・動画には対応していません。
・端末の写真アクセス権限が必要です。拒否した場合も、既に読み込んだ一覧は表示されます。
```

## 4. スクリーンショット

`store/screenshots/` に配置。Google Play の要件は次のとおり。

| 項目 | 要件 |
| --- | --- |
| 形式 | PNG または JPEG |
| 最小 | 320px |
| 最大 | 3840px |
| アスペクト比 | 16:9 〜 9:16 の範囲 |
| 枚数 | 2〜8 枚（最小 2 枚） |

用意した画像（1200x1920、9:16）:

| ファイル | 内容 |
| --- | --- |
| `01-folder-list.png` | フォルダ一覧。代表サムネイルとタグバッジ |
| `02-image-grid.png` | 画像グリッド。複数の写真が並ぶ |
| `03-viewer.png` | ビューア。ページスクラバー付き |
| `04-tags.png` | タグバッジと「前回の続き」カード |

**すべて合成画像を使っている。** 実在の写真・第三者の個人情報は含まない。
サンプル画像は `scripts/make-sample-images.py` で再生成できる。

## 5. グラフィック素材

| 用途 | ファイル | サイズ | 要件 |
| --- | --- | --- | --- |
| アプリアイコン | `store/icon-512.png` | 512x512 | 32bit PNG、アルファ可 |

```powershell
python -X utf8 scripts\make-feature-graphic.py
python -X utf8 scripts\make-sample-images.py
```

## 6. データセーフティ申告

Play Console の「データ セーフティ」で申告する内容。**実装と一致させること。**

| 質問 | 回答 | 根拠 |
| --- | --- | --- |
| アプリはユーザーデータを収集または共有しますか | **いいえ** | ネットワーク権限なし。外部送信のコードなし |
| データは暗号化されて転送されますか | 該当なし | 転送しない |
| ユーザーはデータの削除を要求できますか | 該当なし | 収集しない |
| 位置情報 | 収集しない | 権限を宣言していない |
| 個人情報 | 収集しない | 同上 |
| 写真と動画 | **端末内でのみアクセス** | `READ_MEDIA_IMAGES`。外部送信なし |
| ファイルとドキュメント | 端末内でのみアクセス | バックアップ JSON の読み書き (SAF) |
| アプリのアクティビティ | 収集しない | 解析 SDK なし |
| アプリの情報とパフォーマンス | 収集しない | クラッシュ報告 SDK なし |
| デバイスまたはその他の ID | 収集しない | 広告 ID 不使用 |

### 権限の用途説明

`READ_MEDIA_IMAGES` について、Play Console で用途を記述する。

```
端末に保存された写真を一覧・表示するための中核機能に使用します。
写真は端末内でのみ読み取り、外部へ送信しません。
アップロード・共有・解析は行いません。
```
