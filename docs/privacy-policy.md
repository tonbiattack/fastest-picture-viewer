# Pictobi プライバシーポリシー

最終更新日: 2026-11-20

Pictobi（以下「本アプリ」）は、個人が開発・提供する Android 向けの画像ビューアです。
本ポリシーは、本アプリが扱う情報と、その取り扱いについて説明します。

## 1. 要点

- 本アプリは**ネットワーク通信を行いません**。インターネット権限を宣言していません。
- 写真・閲覧履歴・タグ・お気に入りを**端末の外へ送信しません**。
- 広告・解析 SDK・クラッシュ報告 SDK・アカウント登録は**ありません**。
- 収集する個人情報は**ありません**。

## 2. 本アプリが扱う情報

本アプリは、機能の提供のために次の情報を**端末内でのみ**扱います。

| 情報 | 用途 | 保存先 | 外部送信 |
| --- | --- | --- | --- |
| 写真（画像ファイル） | 一覧・表示 | 端末のストレージ（元の場所） | なし |
| 写真のメタ情報（ファイル名・更新日時・サイズ・フォルダ） | 一覧の表示と並び替え | アプリ専用のデータベース | なし |
| タグ、フォルダ・画像のお気に入り、除外フォルダ | 整理と絞り込み | アプリ専用のデータベース | なし |
| 表示設定（列数・並び順など） | 表示の再現 | アプリ専用の設定領域 | なし |
| スクロール位置、「前回の続き」の履歴 | 前回の位置の復元 | アプリ専用のデータベース・設定領域 | なし |
| サムネイルのキャッシュ | 表示の高速化 | アプリ専用のキャッシュ領域 | なし |

これらは端末内にのみ保存され、開発者を含む第三者が取得することはありません。

## 3. 写真へのアクセス

本アプリは、写真を一覧・表示するために次の権限を使用します。

- `READ_MEDIA_IMAGES`（Android 13 以降）: 端末の写真を読み取る
- `READ_MEDIA_VISUAL_USER_SELECTED`（Android 14 以降）: 利用者が選んだ写真のみを読み取る
- `READ_EXTERNAL_STORAGE`（Android 12 以前）: 同上

**写真の読み取りのみ**を行います。写真の削除・変更・他のアプリへの送信は行いません。
権限を許可しない場合、本アプリは写真を表示できませんが、既に読み込んだ一覧の情報は表示されます。

## 4. バックアップ機能

本アプリは、タグ・お気に入り・除外フォルダ・表示設定を JSON ファイルへ書き出せます。

- 保存先は**利用者が選びます**（Android のファイル選択画面）。
- 書き出したファイルは利用者の管理下にあります。本アプリが自動で外部へ送ることはありません。
- ファイルには個人情報（フォルダ名など）が含まれる場合があります。取り扱いにご注意ください。

## 5. 第三者への提供

本アプリは、いかなる情報も第三者へ提供・販売・共有しません。

## 6. 広告・解析

本アプリは、広告を表示せず、アクセス解析・行動追跡・クラッシュ報告の仕組みを含みません。

## 7. データの削除

本アプリが保存する情報は、次の方法で削除できます。

- アプリ内の「画像キャッシュを削除」: サムネイルのキャッシュのみ削除
- Android の設定からアプリのデータを消去: 本アプリが保存したすべての情報を削除
- 本アプリをアンインストール: 同上

**写真そのものは削除されません。** 写真は端末の元の場所に残ります。

## 8. 子どもの利用

本アプリは特定の年齢層を対象としたものではなく、子どもから個人情報を収集することはありません。

## 9. ポリシーの変更

本ポリシーを変更する場合は、この文書を更新し、最終更新日を改めます。
重要な変更がある場合は、アプリの更新情報でお知らせします。

## 付記: 実装との対応（開発者向け）

このポリシーの記述が実装と一致していることを、次の方法で確認できます。

| 記述 | 確認方法 |
| --- | --- |
| ネットワーク通信を行わない | `app/src/main/AndroidManifest.xml` に `INTERNET` 権限がない |
| 解析 SDK を含まない | `gradle/libs.versions.toml` に解析系の依存がない |
| 写真を削除しない | `MediaStore` への書き込み API を呼んでいない |
| 外部送信しない | ネットワーク関連の API を呼んでいない |

依存ライブラリを追加したときは、この表の確認をやり直すこと。
